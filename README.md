Applikationen är en enkel konsollapplikation för att hantera bokningar av mötesrum. Den innehåller funktioner för att skapa nya bokningar, visa bokningar sorterade efter datum och starttid, söka efter bokningar och avboka befintliga bokningar.

I applikationen finns kontroller för att bokningens uppgifter är giltiga, det finns tid för bokningen som inte överlappar andra bokningar och att dem bokningsbara rummen är tillräckligt stora.

Applikation startas genom att man öppnar visual studio och clonar repositoryt med hjälp av länken som finns om man trycker på den gröna "Code" knappen. Testerna körs sedan genom att man öppnar "Test Explorer" inne i visual studio. Markerar dem testar man vill köra och trycker sen på den gröna "play" knappen.

För att starta applikationen så högerklicka på "BookingSystem" i Solution Explorer och kontrollera att det är valt som "Startup Project". Tryck sedan Ctrl + F5 alternativt klicka på den gröna "Play" knappen högt upp i mitten på sidan. Konsolapplikationen ska nu finnas tillgänglig på din skärm. Ange siffran för önskat menyval och tryck "Enter".
För att avsluta applikationen tryck "0" och avsluta med "Enter".
